# Installation

Graphics Creator can be installed on Windows and Linux.

## Windows

Download the latest setup executable from the [GitHub releases page](https://github.com/chocolateimage/graphics-creator/releases/latest).

## Linux

### Flatpak

On Linux, Flatpak is currently used as the primary distribution format.

### AUR

There is also an AUR repository: [`graphics-creator`](https://aur.archlinux.org/packages/graphics-creator).
