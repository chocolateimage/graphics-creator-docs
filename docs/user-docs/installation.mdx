# Installation

Graphics Creator can be installed on Windows and Linux.

## Windows

Download the latest setup executable from the [GitHub releases page](https://github.com/chocolateimage/graphics-creator/releases/latest).

The built-in updater will notify you when an update is available. If you accept, it will automatically download and install the update. If you have disabled the updater, you can download and run the latest setup executable to update to the new version.

## Linux

### Flatpak
